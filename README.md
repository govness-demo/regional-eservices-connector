# Regional e-services API connector

OpenAPI client for the regional e-services platform: applications, statuses and appointment booking.

## Overview

A typed client and OpenAPI description for the regional platform, so assistants can check an application's status or book an appointment for a resident.

## Interfaces

Protocol: `openapi`. Languages: uk, en.
